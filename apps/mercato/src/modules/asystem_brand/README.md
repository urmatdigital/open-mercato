# asystem_brand

Имя продукта на экране входа. Ядро задаёт `auth.login.*` в модуле `auth`, а
словари модулей перекрывают словарь приложения (`loadDictionary` мержит
модульные поверх app), поэтому подмена лежит здесь, а не в `apps/mercato/src/i18n`.

Модуль обязан стоять в `modules.ts` ПОСЛЕ `auth` — порядок и решает, чьё
значение останется.
